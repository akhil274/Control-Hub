CONTROLHUB - PARTS LIST
=======================

1.ESP32 Development Board
2.DS3231 RTC Module
3.4-Channel Relay Module 5V
4.Power Supply 5V (2A regulated)
5.CR2032 Battery
6.Electrical extension board / Enclosure

WIRING
======
ESP32 GPIO 21 -> RTC SDA (I2C)
ESP32 GPIO 22 -> RTC SCL (I2C)
ESP32 3.3V -> RTC VCC
ESP32 GND -> RTC GND

ESP32 GPIO 25 -> Relay IN1 (Channel 1)
ESP32 GPIO 26 -> Relay IN2 (Channel 2)
ESP32 GPIO 27 -> Relay IN3 (Channel 3)
ESP32 GPIO 32 -> Relay IN4 (Channel 4)
ESP32 VIN / 5V -> Relay VCC (5V)
ESP32 GND -> Relay GND
